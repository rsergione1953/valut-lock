# 🗄️ SPsoft Password VaultLock

Un gestore di password desktop essenziale, sicuro ed elegante sviluppato in Python.

## 🌟 Caratteristiche
- 🔐 **Cifratura AES-256 (Fernet)**: I dati sono protetti da Master Password e PBKDF2 (100.000 iterazioni).
- 🎨 **Interfaccia Grafica Curata**: Realizzata con CustomTkinter con colori caldi, bordi arrotondati e stile 3D.
- 🎯 **Funzioni Essenziali**: Ricerca rapida, aggiunta, modifica, eliminazione e copia della password negli appunti.
- 💾 **Database Locale**: Salva le credenziali in un database SQLite cifrato in locale (`passwords_vault.db`).
